# Computer Science Collection

A combined collection of data structures and algorithms, computer science notes, and low level design exercises.

## Contents

| Folder | Topics | Languages and tools | Source |
| --- | --- | --- | --- |
| [`Algorithms/`](Algorithms/) | Data structures, graph algorithms, dynamic programming, sorting, trees, interview preparation, and online judge solutions. | C++, Java | [pranay2063/Algorithms](https://github.com/pranay2063/Algorithms) |
| [`CS17/`](CS17/) | Java fundamentals, object oriented programming, operating systems, database concepts, and computer science notes. | Java, C++ | [pranay2063/CS17](https://github.com/pranay2063/CS17) |
| [`LLD/`](LLD/) | Low level design examples for caching, logging, producer-consumer, publish-subscribe, and rate limiting. | Java, Maven | [pranay2063/LLD](https://github.com/pranay2063/LLD) |

Each folder preserves the source repository's internal structure and README files. See [SOURCES.md](SOURCES.md) for the source branches and commit snapshots.

## Working with the examples

The collection brings together independent study repositories, so there is no single build or test command. Follow the instructions in each folder. The `LLD` folder includes its own Maven `pom.xml`.
